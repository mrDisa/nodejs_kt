# Контрольные точки по Node.js

Учебные работы собраны в одном репозитории. Каждая контрольная точка — отдельный проект со своими зависимостями и командами запуска.

| Работа | Тема | Исходники |
|---|---|---|
| КТ1 | CLI-фильтр CSV по возрасту и городу | [kt01](./kt01/) |
| КТ2 | REST API каталога товаров: CRUD, Joi, Multer, фильтрация, пагинация | [kt02](./kt02/) |

## Запуск КТ1

```bash
cd kt01
npm ci
cp .env.example .env
npm start
```

Параметры фильтрации задаются в `kt01/.env`. Исходный CSV: `kt01/data/users.csv`. Результат: `kt01/data/result.csv`.

## Запуск КТ2

```bash
cd kt02
npm install
cp .env.example .env
npm start
```

API: `http://localhost:3000/api/products`. Все маршруты, поля и примеры запросов описаны в [README второй работы](./kt02/README.md).

**Важно:** команды запускайте из папки конкретной КТ. Файлы `.env`, `node_modules` и сгенерированные результаты не добавляются в Git.
